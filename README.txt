LAT39 DESIGNS — STARTER WEBSITE
================================

FILES
-----
index.html      Main website page
styles.css      All visual styling
privacy.html    Simple starter privacy page
assets/         Put your logo and product photos here

FIRST EDIT TO MAKE
------------------
Open index.html in a text editor and find:

    mailto:YOUR-EMAIL-HERE

Replace YOUR-EMAIL-HERE with the email address you want customers to use.

HOW TO PREVIEW
--------------
1. Extract this ZIP file.
2. Open the folder.
3. Double-click index.html.
4. It should open in your normal web browser.

Nothing is published to the internet just by opening the file.

ADDING A PRODUCT PHOTO LATER
----------------------------
Put your image inside the assets folder, for example:

    assets/bottle-holder.jpg

Then the HTML can be changed to use that image in place of the placeholder.
ChatGPT can help make that change when you have the photos.

PUBLISHING
----------
This site is designed to work directly with GitHub Pages. No build process,
database, Node.js, WordPress, or other software is required.
